  mocking and test data seeding for isolated runs.
- Set up monitoring: Prometheus metrics, Grafana dashboards, alerting rules with Slack integration.
- Integrated the tests into CI/CD (GitHub Actions, GitLab CI); testing in Docker and Kubernetes.
- Lead a frontend development team, with hands-on work in React.

**QA Engineer, freelance** · 2024 – 2025
